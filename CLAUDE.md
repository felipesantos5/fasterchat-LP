## Design Context

### Users
- **Primary**: Donos de pequenos/medios negocios brasileiros (restaurantes, clinicas, saloes, lojas) que usam WhatsApp como canal de vendas
- **Secondary**: Profissionais de marketing digital e automacao (gestores de trafego, agencias)
- **Job to be done**: Automatizar atendimento WhatsApp com IA para vender mais sem contratar

### Brand Personality
- **3 palavras**: Ousado, rapido, inovador
- **Tom**: Direto e confiante, linguagem acessivel mas nao infantil
- **Emocao**: Confianca e seguranca

### Aesthetic Direction
- Moderno e limpo com momentos de ousadia. Light mode principal + secoes dark para contraste
- Emerald green (#059669) primaria, slate neutros
- Plus Jakarta Sans (display) + Inter (body)
- Anti: nao parecer template SaaS generico, nao parecer "feito por IA"

### Design Principles
1. Resultado primeiro — cada elemento reforca beneficio ou acao
2. Confianca pela clareza — hierarquia forte, espacamento generoso
3. Ritmo visual — alternar claro/escuro, variar espacamentos
4. Mobile-first pragmatico
5. Ousadia com proposito

### Tech Stack
- Static HTML, pre-compiled Tailwind CSS, AOS animations, self-hosted fonts (woff2), WCAG AA
