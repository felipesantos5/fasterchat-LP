1 Descrição do Serviço

O FasterChat CRM é uma plataforma SaaS (Software as a Service) que oferece:

  • Gestão de WhatsApp: integração e gestão de instâncias via APIs de terceiros (Evolution API), permitindo envio e recebimento de mensagens.
  • Automação com IA: atendimento automatizado utilizando modelos de Inteligência Artificial de provedores como OpenAI e Anthropic.
  • Funil de Vendas (Pipeline): organização e acompanhamento de leads e oportunidades.
  • Campanhas de Mensagens: disparo programado de mensagens para listas de contatos.
  • Integração com Google Calendar: sincronização de agendamentos.
  • Flow Builder: criação de fluxos automatizados de atendimento.
  • Gestão Multiagente: atribuição de conversas a diferentes atendentes da equipe.

4 Proteção de Dados — Conformidade com a LGPD

Esta seção descreve como o FasterChat CRM trata dados pessoais no contexto da Lei nº 13.709/2018 (LGPD).

4.1 Papéis no Tratamento de Dados

O FasterChat CRM atua em dois papéis distintos:

Controlador de Dados

Em relação aos dados dos próprios Usuários e responsáveis pela conta contratante (nome, e-mail, cargo, dados de pagamento), para os quais o FasterChat determina as finalidades e meios do tratamento.

Operador de Dados

Em relação aos dados dos clientes finais dos Usuários (contatos de WhatsApp, conversas, informações de pipeline), tratados por instrução e em nome do Usuário Contratante, que é o Controlador perante seus clientes.

O Usuário Contratante, ao utilizar o FasterChat CRM para tratar dados de seus clientes, assume as obrigações de Controlador previstas na LGPD, incluindo garantir base legal adequada para o tratamento.

4.2 Dados Pessoais Tratados

Dados dos Usuários da plataforma (como Controlador):

  • Nome completo, e-mail, cargo e telefone
  • Dados de acesso (credenciais criptografadas)
  • Dados de pagamento (processados por provedor certificado — não armazenamos dados de cartão)
  • Logs de acesso e atividades (conforme exigido pelo Marco Civil da Internet)

Dados dos contatos gerenciados (como Operador):

  • Número de telefone (WhatsApp), nome, histórico de conversas
  • Informações inseridas pelo Usuário Contratante (tags, notas, estágio de pipeline)
  • Metadados de mensagens (data, hora, status de entrega)

4.3 Bases Legais para o Tratamento

O FasterChat utiliza as seguintes bases legais previstas no Art. 7º da LGPD:

Finalidade Base Legal

4.4 Finalidades do Tratamento

Os dados são tratados exclusivamente para:

  • Autenticar usuários e controlar acesso
  • Fornecer e operar as funcionalidades contratadas
  • Processar pagamentos e emitir documentos fiscais
  • Suporte técnico e comunicações sobre o serviço

Não utilizamos dados de Usuários ou de seus clientes para fins publicitários de terceiros, nem vendemos dados a terceiros.

4.5 Compartilhamento de Dados com Terceiros

Os dados podem ser compartilhados com:

  • Processadores de Pagamento (ex.: Stripe): para processamento seguro de cobranças, sob acordo de proteção de dados.
  • Provedores de IA (OpenAI, Anthropic): para processamento das mensagens configuradas pelo Usuário para automação com IA. O compartilhamento é limitado ao conteúdo das conversas roteadas para IA.
  • Google: para integração com Google Calendar, mediante autorização explícita do Usuário.
  • Provedores de Infraestrutura: hosting e banco de dados, com acordos de confidencialidade e proteção de dados.
  • Autoridades públicas: quando exigido por lei, ordem judicial ou regulação aplicável.

4.6 Transferência Internacional de Dados

Alguns serviços integrados (OpenAI, Anthropic, Stripe) possuem sede nos Estados Unidos. As transferências internacionais de dados são realizadas com base em garantias adequadas, incluindo cláusulas contratuais padrão de proteção de dados e políticas de privacidade e segurança dos provedores.

4.9 Segurança dos Dados

O FasterChat adota medidas técnicas e organizacionais para proteger os dados pessoais, incluindo:
